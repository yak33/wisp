# Wisp

![Wisp](docs/banner.png)

> 轻若无物的 Windows 效率工具 —— 剪贴板历史 · 备忘快贴 · IP 工具

![Rust](https://img.shields.io/badge/Rust-2024-orange?logo=rust)
![GPUI](https://img.shields.io/badge/UI-GPUI-8A2BE2)
![Platform](https://img.shields.io/badge/Platform-Windows%2011-0078D6?logo=windows)
![License](https://img.shields.io/badge/License-MIT-green)

Wisp（轻烟）是一个常驻托盘、快捷键瞬时唤起的桌面效率工具。它只做少数几件事，并把每一件做到**极致的快**：

- ⚡ **原生 GPU 渲染**：基于 [GPUI](https://www.gpui.rs/)（Zed 编辑器的 UI 框架）+ [gpui-component](https://github.com/longbridge/gpui-component)，无 WebView、无 JS 运行时
- 🪶 **常驻极轻**：实测常驻内存 ~27MB（debug 构建），后台 CPU 恒为 0%
- ⌨️ **键盘优先**：唤起即输入，↑↓ 选择、回车即得，全程无需鼠标
- 🔌 **事件驱动**：剪贴板监听走 `WM_CLIPBOARDUPDATE` 消息，零轮询

## 功能

### ✅ 主页导航（已上线）

- uTools 风格：唤起先落主页，功能以图标网格呈现，点击进入对应功能页
- 搜索框过滤功能（中文名 / 英文别名），↑↓ 选择、回车即入，全程键盘可达
- 规划中的功能置灰占位，路线图内置可见

### ✅ 剪贴板历史（已上线）

- 自动记录文本型剪贴板内容，重复复制不产生冗余条目（原条目自动回到顶部）
- 即时模糊搜索（中文友好，`%`/`_` 等通配符按字面匹配）
- 分类筛选：全部 / 文本 / 图像 / 文件 / 收藏，点击或 `Alt+1~5` 切换
- **图像记录**：截图/复制图像自动入库（4K 以内全收），缩略图列表 + 悬停放大预览，回车/双击/右键交付原图
- **文件记录**：资源管理器 Ctrl+C 的文件列表进历史（100 个以内），悬停列出清单，交付可粘回任意目录
- 置顶收藏，置顶项恒排最前
- 悬停预览完整内容：保留换行截断 500 字符，尾注显示总字符数
- 自动保留策略：未置顶条目 90 天过期、总量 2000 条封顶，置顶豁免
- **回车直达粘贴**：自动还原焦点并模拟 Ctrl+V，内容直接落到你原来的输入框

### ✅ 备忘快贴（已上线）

- 标签化的文本片段库，常用话术 / 密钥 / 模板随手存取
- 左侧标签侧栏带计数，支持「全部 / 无标签 / 指定标签」筛选
- 搜索同时匹配内容与备注；选中回车直接粘贴
- 悬停预览完整内容，尾注附备注 / 标签 / 总字符数
- 在某标签下新建时自动预填该标签，连续录入不用重复输入

### ✅ IP 工具（三段 IP 已上线）

- 内网 IP：从当前活动网络的系统路由中确定主 IPv4
- 公网 IP：绕过系统代理查询本机直连出口
- 代理出口 IP：遵循 Windows 系统代理配置，并标识代理是否改变出口
- 三项后台并行检测、独立反馈；首次进入才查询，唤起与渲染线程不受网络阻塞
- 支持逐项复制、一键刷新、`Ctrl+3` 和托盘菜单直达

### ✅ 设置中心（已上线）

- 自定义全局唤起快捷键：录制式修改（须带修饰键，页内占用组合自动拦截），一键恢复默认
- 隐藏托盘图标（隐藏后仅快捷键唤起、设置页退出）、开机自启开关
- 主题偏好三态选择，与标题栏按钮等效
- 关于面板：版本信息与 GitHub 仓库直达

### 🚧 规划中

- IP 工具增强：IP 归属地 + 常用站点延迟面板
- 数据保留策略自定义（当前为固定的 90 天 / 2000 条）

完整进度见 [docs/PROGRESS.md](docs/PROGRESS.md)。

## 架构

```
wisp
├── crates/core   wisp-core —— 纯 Rust 核心，与 UI 框架零耦合
│   ├── watcher   Win32 message-only 窗口，事件驱动监听剪贴板
│   ├── store     剪贴板存储：指纹去重、置顶排序、模糊检索
│   ├── memo      备忘存储：片段 / 标签多对多，事务化保存
│   ├── ip        三段 IP：主内网地址 + WinHTTP 直连 / 系统代理出口
│   ├── paste     粘贴链路：焦点还原 + SendInput 模拟 Ctrl+V
│   └── service   编排：监听线程 → 工作线程 → 壳层信号
└── crates/app    wisp-app —— GPUI 壳（bin: wisp）
    ├── main      窗口生命周期、托盘、全局快捷键、单实例与事件处理
    └── views     根视图（页面导航 / 焦点 / 显隐）+ 主页网格 + 剪贴板视图 + 备忘视图
```

核心设计取舍：

- **core 与 UI 解耦**：`wisp-core` 不知道 GPUI 的存在，未来更换壳层（或加 CLI）无需动核心；
- **窗口级关注点收口于根视图**：唤起聚焦、失焦隐藏、页面切换统一由 `WispView` 处理，子视图并存时不会互相抢焦点；
- **主页先行**：唤起落在功能网格而非某个具体功能，新功能只加一行表项，导航结构零改动；
- **窗口预创建 + 显隐**：唤起只是一次 `ShowWindow`，体感零延迟；
- **唤起即补查**：窗口每次激活自动重查一次，隐藏期间错过的变更信号不会丢；
- **虚拟列表**：列表仅渲染可视区，数据量与帧率无关。

## 关键机制与技术实现

### 1. 零轮询事件驱动 (`wisp-core`)
- **Message-Only 隐式窗口**：专用监听线程创建 `HWND_MESSAGE` 原生窗口，仅订阅 `WM_CLIPBOARDUPDATE`，线程绝大多数时间挂起在 `GetMessageW`，常驻后台 CPU 恒为 0.0%。
- **异步解耦流水线**：监听线程产生信号后通过通道投递给 Worker，Worker 异步完成剪贴板读取、格式识别与 SQLite 入库，并唤醒 GPUI 壳层，全程无锁阻塞。

### 2. 严苛的粘贴链路与修饰键防粘滞 (`paste.rs`)
- **焦点时序保序**：唤起 Wisp 前捕获当前前台窗口句柄（`GetForegroundWindow`）；交付时先隐藏自身，将前台还给目标窗口并留出 `FOCUS_SETTLE`（80ms）等待焦点落定。
- **修饰键主动释放**：通过 `GetAsyncKeyState` 检测 `Alt / Shift / Win` 物理状态，若用户未松开快捷键即回车，自动发送 `KEYEVENTF_KEYUP` 清除残留修饰键，防止 `Ctrl+V` 被系统识别为 `Ctrl+Alt+V`。
- **独立线程模拟**：在独立工作线程中投递 `SendInput` 序列，彻底避免 Win32 阻塞调用影响 UI 渲染帧率。

### 3. 多媒体与存储安全护栏 (`store.rs` & `service.rs`)
- **指纹预筛与天然去重**：文本采用 64 位 FNV-1a 预筛，重复写入仅更新 `created_at` 并回顶；图像按原图内容哈希命名无损落地 `images/*.png`（物理级去重）。
- **4K 像素熔断**：单张图像严格限制在 4096×4096 像素以内，单条文本限制 2MB，从源头杜绝异常复制导致的内存与磁盘撑爆。
- **自动保留策略（Guardrails）**：未置顶记录 90 天自动过期 + 总量 2000 条封顶淘汰，用户收藏（`pinned = 1`）永久豁免。
- **SQLite WAL 调优**：开启 `WAL` 模式、`synchronous = NORMAL` 与 `busy_timeout(2s)`，保障多连接并发读写互不锁库。

### 4. GPUI 原生 GPU 渲染与极速交互 (`wisp-app`)
- **原生 GPU 渲染管线**：直接构建于 Zed 的 GPUI 与 gpui-component 之上，渲染走 GPU 管道（Windows 上基于 DirectWrite / DX），无 WebView、无 JS 运行时，冷启与呼出均为瞬时（体感 0 延迟）。
- **虚拟列表与解码缓存**：列表基于 `v_virtual_list` 虚拟化渲染，可视区外零开销；图像缩略图缓存为 `Arc<RenderImage>`（BGRA 格式直出），每帧绘制零 CPU 解码损耗。
- **原生 HitTest 窗口拖动**：无边框窗口拖动依托 GPUI 的 `.window_control_area(WindowControlArea::Drag)`，直接交由 Windows `WM_NCHITTEST` 原生处理；交互控件挂载 `.occlude()` 阻断穿透，彻底根治传统 `SendMessage` 导致的事件循环重入崩溃。
- **热键冲突容灾与单实例保护**：默认全局快捷键遇第三方占用自动平滑降级（`Alt+Space` → `Ctrl+Alt+Space` → ``Alt+` ``）；通过 `Local\` 命名互斥量保证单一实例，杜绝多开造成的托盘与热键冲突。

## 构建

```bash
# 依赖：Rust stable (MSVC toolchain)，Windows 10/11
cargo run            # 调试运行
cargo build --release
cargo test -p wisp-core
```

> 首次构建会从源码编译 GPUI 全家，耗时约 10 分钟；此后增量编译在秒级。
